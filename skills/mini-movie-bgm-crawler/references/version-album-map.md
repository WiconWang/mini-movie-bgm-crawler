## 使用说明

1. 用户给版本号 → 查上方"版本发布时间线"表 → 确定地区
2. 根据地区查"地区→OST专辑"表 → 确定搜索关键词
3. 用 musicn 搜索该关键词 → 获取曲目列表
4. 分析 BPM/RMS → 筛选轻柔候选

**注意**：同一版本可能跨多个地区（如 2.6 同时有稻妻新区域和渊下宫），需搜索多个OST专辑。
